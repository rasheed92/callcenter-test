# نظام الكول سنتر — نموذج اختبار التسجيل

تطبيق Android تجريبي لاختبار تدفق العمل وجودة صوت تسجيل المكالمات قبل بناء
النظام الكامل المربوط بسيرفر Mizeej.

## ماذا يفعل
- يعرض "طلب" تجريبي (رقم 1200) مع رقم هاتف الزبون.
- زرّان: اتصال عبر الخط / اتصال عبر واتساب.
- قبل كل مكالمة: إقرار "المكالمة مسجّلة لأغراض الجودة".
- ينشئ جلسة، يشغّل خدمة تسجيل أمامية، ثم يفتح المكالمة.
- يكتشف نهاية المكالمة ويوقف التسجيل ويربط الملف بالطلب.
- شاشة "التسجيلات المحفوظة" لتشغيل كل تسجيل والتحقق من جودته.

## كيف يبني الـ APK
ارفع المجلد إلى مستودع GitHub على فرع `main`. سيبنيه
GitHub Actions تلقائياً. نزّل `callrec-debug-apk` من تبويب Actions ثم Artifacts.

## الإعداد على كل جهاز (مرة واحدة)
1. ثبّت الـ APK (فعّل "تثبيت من مصادر غير معروفة").
2. افتح التطبيق وامنح: المايك، الاتصال، سجل المكالمات، الإشعارات.
3. فعّل خدمة إمكانية الوصول من:
   الإعدادات ← إمكانية الوصول ← "كول سنتر — تجربة" ← تفعيل.
   (في Android 13+ قد تحتاج "السماح بالإعدادات المقيدة" من معلومات التطبيق أولاً.)
4. استثنِ التطبيق من تحسين البطارية.

## اختبار الجودة
- جرّب اتصال خط واتصال واتساب.
- شغّل مكبّر الصوت (السبيكر) أثناء المكالمة.
- افتح "التسجيلات المحفوظة" واسمع: هل صوت الموظف والزبون واضحان؟
- على سامسونج: إن كان صوت الزبون ضعيفاً في مكالمة الخط، استخدم التسجيل
  المدمج بدلاً من هذا الأسلوب لمكالمات الخط.

## ملاحظة قانونية
التطبيق يعرض إقراراً بالتسجيل ويوصي الموظف بإعلام الزبون. التسجيل لأغراض
الجودة والمتابعة الداخلية ضمن الشركة.
